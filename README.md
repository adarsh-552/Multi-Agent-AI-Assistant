# 🤖 Multi-Agent AI Assistant

An AI-powered Resume and Career Assistant built using Python, Streamlit, RAG, FAISS, Sentence Transformers and Groq LLM.

## Features

- 📄 Upload Resume PDF
- 📊 Resume Analysis
- 💻 Technical Skill Extraction
- 🎯 Recommended Job Roles
- 📚 Skill Gap Analysis
- 📈 ATS Resume Score
- 🔍 Resume vs Job Description Matching
- ✨ Resume Improvement
- 🎯 Job-Specific Resume Generation
- 🧭 Career Apply Recommendation
- 💬 RAG-based Resume Q&A
- 📥 TXT and DOCX Resume Download

## Technologies

- Python
- Streamlit
- LangChain
- Groq
- Sentence Transformers
- FAISS
- Python-Docx
- PyPDF
